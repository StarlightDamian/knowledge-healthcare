# 全病种覆盖审计与补充计划

核对日期：2026-10-02。结论：**95%覆盖审核不通过。目录已冻结为13,155个合格末级类别，当前通过完整证据和类别对应审核的分子为2，核验覆盖率约0.0152%。** 该数字表示审核进度，人群病例和疾病负担采用不同口径。

现有75篇（70个疾病或健康问题、5个症状入口）和195个仅标题待办。医学签审0；睡眠呼吸暂停7A41、睾丸扭转GB01.0已确认语义对应并完成逐项编辑核验；其余映射待裁定。完整医学病种分母来自冻结官方目录。

## 固定目标口径

目标为 WHO ICD-11 MMS **2026-01** 的独立病症类别，并以完整中英知识正文为内容门槛。[WHO官方版本列表](https://icd.who.int/docs/icd-api/SupportedClassifications/)确认该版有中英文资料。WHO发布页的630万以上“可检索组合”不是独立病种数，不作分母。[WHO 2026发布说明](https://www.who.int/news/item/16-02-2026-icd-11-2026-release)

冻结目录时逐条保留代码、官方标题、URI、版本、纳入决定和排除理由；原始快照与规则计算哈希。疾病、症状、损伤中毒的合格末级独立类别及“其他／未特指”类别纳入。父级汇总、同义词、扩展码、后组配组合不重复计数；非病症的医疗接触、外因和功能评估另列排除。补充章节单列清单和口径，不静默删除。无法判定的项留在待裁定清单，分母尚未冻结时不报百分比。

公式：正文覆盖率 = 确认类别对应、满足14维度双语内容标准且来源支持成立的唯一类别数 / 冻结合格类别总数。

标题映射、完整正文、医学签审分别统计。疾病跨科室、多个语言版本和别名不增加分子；父级综述不能自动覆盖所有子病种，一篇涉及多个代码必须逐代码说明其实际覆盖范围。退役或过期失效的内容不作为有效覆盖。总体比例和各章结果同时公开，不用常见需求权重替代全部类别的等权分母。

当前 `snapshot_status=frozen`、映射2条确认、2条部分、48条待裁定，严格核验口径 `measured=0.00015203344735841885`。官方 ZIP、逐行纳入与排除、固定规则及哈希已保存至 [data/icd](../data/icd/README.md)。全部35,664个官方类别均有“完整／部分／缺失／范围外”处置状态，见 [全类别状态](../reports/icd-category-status.json.gz)；13,153个未合格类别完整保存于 [剩余缺口](../reports/icd-remaining-gaps.json.gz)，各章计量见 [覆盖结果](../reports/icd-coverage.json)。达到95%至少需要12,498个合格类别。

官方工作表共37,152行（35,664个类别、1,360个区块、28个章节及100个空格式行）。01–22章末级类别包含全部残余类别；25章保留电子烟相关疾病、两类COVID-19、COVID后状态及相关多系统炎症综合征共5项，13个没有具体病症名称的应急占位码排除。传统医学第26章的1,246行单独公开，不计入主分母；具体裁定理由逐行保留。排除工作量、罕见程度和来源收集难度不构成缩小分母的理由。

## 可执行补充批次

| 批次 | 工作 | 验收产物 |
|---|---|---|
| P0 固定目录 | 官方快照和范围已冻结；继续对现有正文和标题建立语义对应，不能把同名候选自动确认 | 快照出处/哈希、全量纳入与排除、真实对应审核；47条同名对应尚待核查 |
| P1 首批最多20篇 | 10项急危重缺口，加ADHD、甲状腺结节、代谢相关脂肪性肝病、子宫内膜异位症、围绝经期症状、玫瑰痤疮、脱发、咳嗽、腹痛、阻塞性睡眠呼吸暂停 | 逐主张证据、14维双语正文、独立对抗审核、逐类别对应；危险提示规则不代替正文 |
| P2 常见症状与科室 | 咳嗽、腹痛、恶心呕吐、心悸、晕厥、便血、血尿；幽门螺杆菌感染、颈痛、接触性皮炎、白内障、龋齿、尿失禁、异常子宫出血 | 按科室验收逐篇知识质量，复算剩余类别，不改分母 |
| P3 全部剩余专科 | 遍历儿科与围产期、感染、肿瘤、神经退行性疾病、遗传罕见病及全部其余合格类别 | 每一未覆盖类别都有负责人/批次/来源状态；罕见类别不因工作量大移出分母 |
| P4 达标复核 | 复核类别对应、正文深度、双语一致性、证据与重复计数 | 真正达到95%才更新 measured；公开各章结果、剩余清单、草稿与医学签审状态 |

P1、P2是优先起步清单，P3以P0的全量剩余类别为范围。每批最多20个规范主题，按急迫性、疾病负担、专科缺口和可核验需求排序。完成首批或198个标题均不是结束条件。每批保存新增、合并、补写、未通过项和剩余缺口，通过证据、数据库和网站验收后才提交并发布。

编辑记录格式见 [逐主张核验说明](../data/evidence/editorial-checks/README.md)。关键行动、阈值、疗效和风险要求两份独立编写的权威支持；反证、地区差异和特殊人群条件须保留。仅有两个网址不能满足该条件。旧5条普通感冒抽查不会自动升级为完整章节；72篇和两个知识模块迁入数据库不会升级医学状态。

## 对抗检查与失败条件

- 14栏非空、每节有列表或字数增长：只能说明结构，不能证明完整。
- 将源链接数量当作证据核验、将医学状态字符串改成“已审”：均不合格；现有哈希绑定与人员门禁仍须通过。
- 没有完整分母、存在未裁定范围却显示百分比：不合格，必须保留null。
- 同义词、多个科室、同一病种不同语言重复计数，或父级自动覆盖子类：不合格。
- 一句话摘要、仅标题、未完成翻译、错误类别对应、退役条目：不能计入完整正文分子。
- 真实医学审校未完成：不得把编辑扩写或自动测试等同于医学签审。

现有 `coverage` CSV命令测的是指定样本的信息需求映射，属于另一指标，不能用于上述病种类别比例。本轮未用其输出宣称95%达标。

### p0-ectopic-pregnancy · P0

先补异位妊娠的及时评估及破裂识别；稳定已确诊病例可由医生监测，不应被正文误写成一律急诊手术。

|---|---|
| 延误敏感性 | 疑似情况及时评估；突发剧痛、晕厥等破裂表现属紧急情形。 |
| 可避免的死亡或功能损害 | 破裂及出血风险；处理方式根据症状和检查决定。 |
| 疾病负担 | 未知（null） |
| 传播与公共卫生 | 未知（null） |
| 特殊人群与公平可及 | 可能怀孕及已妊娠者，包括尚未验出阳性者。 |
| 证据缺口 | 未知（null） |

<a id="rule-p0-maternal-haemorrhage-eclampsia"></a>

### p0-maternal-haemorrhage-eclampsia · P0

优先编写产后出血及子痫；不将全部妊娠、分娩或高血压类别定为P0。

| 医学考虑 | 判断 |
|---|---|
| 延误敏感性 | 写作优先说明新发或急性表现的识别、行动与延误后果；不以编辑等级判断某位患者当前分诊。 |
| 可避免的死亡或功能损害 | 及时处理严重出血或子痫关系孕产妇生命。 |
| 疾病负担 | 未知（null） |
| 传播与公共卫生 | 未知（null） |
| 特殊人群与公平可及 | 妊娠、分娩后人群；孕周及产后阶段需写清。 |
| 证据缺口 | 未知（null） |

来源与定位：[who-maternal](index.md#source-who-maternal)

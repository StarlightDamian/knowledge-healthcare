# 语言与地区：两条独立状态链

本版本界面支持简体中文、英语、西班牙语、法语、巴西葡萄牙语、阿拉伯语、日语、韩语、德语、俄语、印地语、印度尼西亚语。阿拉伯语设置 RTL；桌面侧栏保持左侧、语言选择保持右上角。切换语言保留科室、查询、比较选择和已打开的详情。所有 UI 翻译均为编辑稿；科室名称及医学字段标题使用中英回退，不能宣称完整地区本地化。

医学正文只有 `zh-CN` 和 `en`，同样没有医学翻译签审。选择其他界面语言会醒目说明“医疗正文为英语”，不静默假装已经翻译。症状检索和危险表达只覆盖有限中英词项，不保证使用其他十种语言输入症状能召回或触发提醒。英文标题、部分国际缩写可能被匹配，这不构成完整语言支持。

`clinical_region` 与语言无关。当前所有主题为 UNSPECIFIED：不把 NHS 的英国路径自动解释成中文地区的法律/用药标准，不根据浏览器语言猜急救号码，不提供地区药品批准或处方身份的未经核验结论。科室提供常见导航角色，实际挂号入口需按当地医疗机构确认。

后续应使用 `condition_id + content_locale + clinical_region` 的版本覆盖关系；现在是支持中英文本的单一主题文件，并未实现多地区推荐自动选择。翻译流程：原文证据核实 → 医学译文 → 反向核对关键否定/禁忌/单位/年龄 → 本地医生与药师审查 → 内容绑定签审。自动翻译不直接产生临床发布状态。

12 种 UI 不计作 12 种已审医学指南。即使补齐每个字符串，也不能自动解决当地疾病谱、卫生服务可及性或药物规则差异。

# 安全边界与失效模式

本项目展示通用资料，不对个人作确诊、处方、风险概率或“无需就医”保证。出现严重、突然或令人担忧的症状，应联系当地急救或专业医疗人员；不要等待网页搜索结果。危险模式未命中不表示安全。

## 当前危险提示是什么

12 条中英短语模式和一条结构化小月龄婴儿发热提示。它是规则草稿，不是完整分诊算法。它在分类/结果筛选之前独立运行，因此不会被“眼科”筛选隐藏胸痛相关提醒。未知语言、复杂叙述、年龄、否定、病史和时间关系都可能处理错误。

## 实测发现并修复的错误

分句器一度把“不过”作为转折词，导致“喘不过气”被切开，严重呼吸困难规则没有命中。修复方式是移除此不安全的通用切分；增加固定阳性回归测试并在浏览器验证。这个例子说明仅有漂亮 UI 和来源列表不足以保证提示安全。合成测试通过也不意味着其他未见表达不会漏掉。

## 不应声称已经具备的能力

没有完整症状医学语义理解、所有急症/年龄场景、多语分流、个体化风险分层、诊断排除、药物相互作用引擎、处方剂量算法、流行病学95%覆盖、独立临床验证或全面无障碍认证。自动审核只检查记录一致性，不能证明临床正确性。

## 常见风险及控制

| 风险 | 本版处理 | 残余风险 |
|---|---|---|
| 排名被当作诊断 | 相关主题措辞、无概率 | 用户仍可能过度推断 |
| 否定误读 | 局部分句/否定测试 | 任意复杂语言未覆盖 |
| 内容错误或过期 | 待审标识、来源 ID、复核日期 | 没有临床编辑团队签审 |
| 儿童/妊娠误套成人路径 | 专门段落、局部规则、警告 | 尚无完整亚组验证 |
| 药物伤害 | 只描述角色/风险，不生成个人剂量 | 读者仍可能自行用药 |
| 来源多但不支持主张 | 支持状态与链接分离 | 全字段核验未完成 |
| 恶意 HTML / CSV | 安全 DOM、脚本转义、公式防护 | 仍需生产安全审计 |
| 隐私 | 查询本地，不保存历史 | 托管访问日志/外链由第三方管理 |

# 证据政策：主张级核查，不是链接堆积

## 一条事实经历的不同状态

`source located → page/abstract inspected → claim support mapped → independence checked → clinical review → regional/translation review → published for a defined purpose`

URL 可访问只是链接状态。题目相关只是主题状态。一条具体主张被支持才是证据状态。医生签审又是另一状态。不得把来源检索日期记成医学审核日期；不得把标题命中记成全文阅读。

来源登记的当前数量见[来源审计](../reports/source-audit.json)；72 个主题各保留至少两个候选来源家族。多数为 NHS、NIH 专门机构、CDC、WHO 的公众健康资料，另有 NICE 指南和少量原始试验。**本库不是已经完成系统综述的数据库，也没有用 NEJM/JAMA 等品牌替代逐主张证据审核。** 本轮扩写记录实际检查的页面与章节，详见[编辑核对记录](../reports/content-expansion/)；来源章节核对不等于逐主张独立医学签审。既有5条普通感冒窄主张抽查也不升级整篇审核状态。

## 资料优先级按问题决定

治疗路径优先目标地区适用且有效的正式指南；疗效与伤害需系统综述及关键原始试验；诊断需诊断准确性研究和诊断标准；自然病程和罕见伤害往往需要观察证据。公众资料帮助写明可读的就医提示。不能用“所有 RCT 都高于所有指南”或“某期刊都是 A 级”代替方法评价。

WHO 的指南方法明确包含系统检索、综合、质量评价、利益冲突管理、获益伤害和使用者偏好：https://www.who.int/groups/guidelines-review-committee 。本项目不声称已经对各主张完成 GRADE；`evidence_certainty=not_formally_graded`。

## 一条高风险主张的核验单

记录问题、适用地区/人群、干预/比较/结局（适用时）、来源版本与日期、研究设计、精确支持位置、支持程度、利益冲突、风险偏倚、是否间接/过期、其他权威来源的一致或冲突处。药品、危险信号、儿童、妊娠和严重不良反应需要额外专科/药师审核。

本项目将“两条独立来源”设为发布门槛之一，而非医学界统一的充分标准。如果仅有一条有效权威指南，应记录证据不足/单指南依据并调整适用范围，不能为了过 CI 引入无关来源。当前严格门禁尚不支持例外发布，例外需要治理审议和专门实现，不能直接篡改状态。

## 独立性不是域名数量

PubMed 是书目与摘要入口，不是所有文章的作者；MedlinePlus 部分百科由 A.D.A.M. 提供，不能将宿主 NIH 和原创作者误当两份独立研究。两份指南引用同一试验也可能共享底层证据。登记 `independence_group` 只是第一层组织独立性，需要继续分析底层证据依赖，不能把两个来源家族宣传为完全独立验证。

## 冲突、更新与撤稿

保留不同来源的地区、人群、发布日期和版本，不按票数平均推荐。当前记录了 NHS 使用 PMOS 与其他来源保留 PCOS 的名称差异；它是术语状态差异，不是擅自宣布全球改名。

每次来源更新应执行 `python -m src.guide impact SOURCE_ID`，列出所有依赖字段，重新核对并绑定新版哈希。来源记录的元数据哈希不等于已归档网页正文哈希；高保证审查还需合法的原文版本留存/定位及变更监控。HTTP 检查不能发现推荐改变、撤稿或医学错误。

## 论文卡的真实阅读范围

SPRINT、Novel START、Morin CBT-I：摘要级原始试验草稿，保留人群和外推局限。SPRINT 登记更正链接，但未独立审计更正全文。UKPDS34：仅书目元数据，未抽取治疗结论。没有把没有取得的全文包装为“全文交叉审查”。在采用结论前应检索完整论文、补充材料、更正、后续证据和现行地方指南。

## 签审记录

`reviewers.json` 当前为空。填入审核者前由项目治理人员核验实际资质并取得其公开同意；不在公开仓库上传身份证件等敏感凭证。审核 attestations 绑定 `content_sha256`；字段核验绑定 `text_sha256`、`source_sha256`、`locator` 和 reviewer ID。

软件校验不能鉴别伪造人员/记录。应配置真实 CODEOWNERS、受保护分支、利益冲突声明和双人合并规则。本交付仅含 CODEOWNERS 示例，未虚构医生或组织账号。

医学发布记录至少需要一名医生，不能仅由两名药师登记满足整篇疾病主题的发布门槛；这仍不替代真实资质核验。
